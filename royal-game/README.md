# Crown & Castle

Original fantasy match-3 puzzle game for Web and Android-ready PWA development.

## Current prototype
- Responsive mobile-first royal purple / antique gold interface
- 8×8 match-3 board with adjacent swaps, match detection, gravity and refill
- Level goals, move counter, score, rewards and local progress save
- 10 level progression scaffold
- Online social and tournament navigation placeholders are clearly marked as coming soon

## Run locally
```bash
cd royal-game
npm install
npm run dev
```

## Build
```bash
npm run build
```
